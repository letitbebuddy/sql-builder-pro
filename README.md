# SQL Builder Pro

## Live Demo

https://sql-builder-pro.streamlit.app

## Overview

Generate Snowflake DDL, FILE FORMAT, STAGE, COPY INTO and MERGE scripts from CSV or Excel files.

## Features

- CSV Upload
- Excel Upload
- Data Preview
- Data Profiling
- Snowflake CREATE TABLE Generation
- FILE FORMAT Generation
- STAGE Generation
- COPY INTO Generation
- MERGE Generation
- Download Full SQL Package

## Tech Stack

- Python
- Streamlit
- Pandas
- Snowflake SQL

## Run Locally

pip install -r requirements.txt

streamlit run app.py
